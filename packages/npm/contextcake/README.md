# ContextCake CLI

The supported Node 22+ command-line distribution of ContextCake. It has no
runtime dependencies, lifecycle scripts, account requirement, or telemetry.

```sh
npx contextcake@<version> --help
contextcake mcp --manifest /absolute/path/to/manifest.json
```

For the signed Mac app and other verified install methods, visit
<https://contextcake.com/install>.
